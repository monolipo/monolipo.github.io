Proposal language: all scientific and technical text fields must be written in English. The interface remains bilingual to assist preparation. All information stays in your browser until you download the proposal file or PDF.

1. Basic Information / Informações básicas

Identify the scientific program concisely and classify the dominant area.

Use a clear scientific title. Avoid relying only on the target name.
Maximum 1000 characters and approximately 150 words.

2. Investigators / Equipe

Provide complete contact information for the PI and each co-investigator. Two co-authors are recommended, but additional members are allowed.

Principal Investigator (PI)

Co-Investigators

Recommended: up to two members.

3. Observing Request / Solicitação observacional

Select exactly one observing mode and define the requested allocation.

4A. Photometric Configuration

Define the acquisition configuration and justify the requested cadence and precision.

Quick exposure-time estimator

Enter the target magnitude and required SNR.
Empirical guide only. The proposal must still address saturation, cadence, sky, airmass and comparison stars.

4B. Spectroscopic Configuration

Define the spectral region, resolution, slit strategy, calibration and SNR requirement.

Quick exposure-time estimator

Specify the wavelength, magnitude and SNR.
State whether the SNR is per pixel or per resolution element and where it is evaluated.

5. Target List / Lista de alvos

Include science targets, standards and comparison fields. Coordinates should be sexagesimal or decimal and unambiguous.

TargetRADecMag.BandTypePriorityExp. (s)FramesVisitsComments
Add exposure times and frame counts to estimate the execution time.

6. Scientific and Technical Case

Connect the scientific question to an observable, required precision, instrument configuration and analysis plan.

Recommended maximum: one page in the generated PDF.

7. Figures and Tables / Figuras e tabelas

Optional. Up to two figures are accepted in the generated PDF.

8. Declaration

Confirm that the proposal is complete and technically defensible.
